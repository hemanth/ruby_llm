Interactive Codelab

Build AI features the Ruby way

RubyLLM is the Ruby-native AI framework. Work with models, tools, and agents through one consistent API, in plain Ruby or Rails. Write and run real Ruby directly in your browser.

$ bundle add ruby_llm
quickstart.rb 
# The Ruby-native AI framework
chat = RubyLLM.chat(model: "claude-sonnet-5")
chat.with_instructions("You are a Rails expert.")

response = chat.ask("Hello from RubyLLM!") do |chunk|
  print chunk.content
end

puts "Tokens: #{chat.tokens.total} | Cost: #{chat.cost}"
